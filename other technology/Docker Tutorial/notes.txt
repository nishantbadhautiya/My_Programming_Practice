Run the application stack with:
        docker-compose up -d  # run in same directory where dockerfile is present 
Access the MySQL container:
        docker exec -it mysqldb mysql -u root -p
Access the Python app container:
        docker exec -it mypyapp bash
Verify the health of services with:
        docker inspect mysqldb
View logs for debugging:
        docker-compose logs
Restarting Services
        docker-compose restart
Scale the number of container instances: 
        docker-compose up --scale web=3  # Scaling Services
